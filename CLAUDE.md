# readlater-privacy

The privacy policy for Clipfile. One hand-written `index.html`, no build step. Repo:
`github.com/shearmds/readlater-privacy`.

**Treat this as a published legal document, not a web page.** It is what the App Store listing
points at, so it has to keep describing what the apps actually do. When app behaviour changes in
a way that touches data handling, this file changes too — the Gemini folder-categorization
disclosure is the precedent.

Published via `mikeshear-site`, which clones this repo to `/coding/research-sync/privacy` at
build time. Pushing here does **not** update mikeshear.com until `mikeshear-site` rebuilds.

The rest of the family: `ReadLater` (iOS app), `readlater-sync` (Worker), `dia-read-later`
(browser extension), `read-this-later` (Raycast), `ReadThisLater` (marketing site).
